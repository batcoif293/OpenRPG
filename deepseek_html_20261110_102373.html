RPG Studio — Help

A quick guide to every tool, panel and feature.

Top Toolbar

Project

  • New — start a fresh project (current work is discarded).
  • Save — download the whole project as a .rpgproj.json file.
  • Load — open a previously saved project file.

View tabs

  • Map — paint tiles and place events on the selected map.
  • UI — design the on-screen interface (sprites + dynamic text).
  • Help — this page.

Tools

  • Paint — stamp the selected tile. Right-click erases. Drag to paint a line.
  • Fill — flood-fill a connected region with the selected tile (or clear it with right-click).
  • Remove — clear tiles on the active layer.
  • Event — click an empty cell to create an event (it also appears in the World directory).
  • Select — drag an existing event to a new cell; double-click to edit it.

Other buttons

  • Map Settings — size, tile size and tileset for the current map.
  • Project Settings — project name and the global variable list.
  • Zoom − / + — zoom the map view. Ctrl + mouse-wheel also zooms.
  • Play Test — run the current map in the editor. Press Esc to stop.

World Directory

Everything that lives in the game world is listed here. Use + New to add items.

Map

A grid of tiles. Click the name to open it; use ▸ / ▾ to expand it and see the events that belong to it. The ✎ button opens its properties, ✕ deletes it.

Events (under a map)

Events that live on a map. They can trigger by Action Button (player presses Space facing it), Player Touch (player walks onto it) or Autorun (runs once when the map loads). Use Add Event inside an expanded map, or the Event tool on the canvas.

Global Events

Events that are not attached to a map. They can only trigger on Game Start or when the player enters a map (optionally limited to one map).

Player

The character the player controls. Click a player to edit its name, sprite sheet, speed and whether it is the Primary player (the one used in Play Test). You can have several players.

Camera

Optional. A camera belongs to a player (usually the Primary player). Its view width controls zoom: fewer squares = more zoomed in, more squares = more zoomed out. Without a camera the view is 1:1 pixels.

+ New menu

  • Map — create a new map.
  • Player — add another playable character.
  • Camera — attach a camera to the Primary player.
  • Global Event — an event that runs on game start / map enter.
  • NPC / Chest — preset events placed on the current map (a friendly example to edit).

Sprite Sheets

  • Import — pick an image, set the frame size, choose which frames belong to each direction, and optionally mark it as a tileset or make white pixels transparent.
  • White → transparent — any near-white pixel becomes transparent. Toggle it later in the sheet properties (✎).
  • Tileset — tick “Use as a tileset” to paint with it on maps.
  • Animation slots — besides down / left / right / up you can add custom slots (e.g. idle, attack) in the sheet properties. Events can use any slot as their facing.

Tiles Panel

  • Tileset select — choose which tileset the current map uses.
  • Ground / Decor / Collision — the active paint layer. The Collision layer paints red blocks that stop the player.
  • Click a tile in the palette to select it, then paint on the canvas.

Events

Triggers

Map events: Action, Touch, Autorun. Global events: Game Start, Map Enter.

Commands tab

  • Show Text — a dialogue box. Space / Enter advances it.
  • Show Choices — a menu of options; each option has its own command list.
  • If Variable — branch on a variable (numbers compare numerically).
  • If Key Pressed — branch while a key is held.
  • Set Variable — set / add / subtract.
  • Move Character — walk the player or an event a number of tiles.
  • Wait — pause for a number of frames (60 = 1 second).
  • Change Map — teleport the player to another map and position.
  • Change Sprite — swap the sprite sheet of the player or an event.
  • Cooldown — stop the event from re-triggering until the player walks away (or for a fixed time). Great for NPCs so you don’t talk to them again by accident.
  • Comment — a note, does nothing.

Advanced tab

  • Hitbox — the collision box (independent of the sprite). Adjust its X/Y offset and width/height in tiles.
  • Blueprint — a node graph alternative to the command list. Tick “Use blueprint graph” to run it. Drag from an output pin to an input pin to link nodes. Right-click a link to delete it. Right-click empty space to add a node, drag to pan, wheel to zoom.

UI Editor

Add sprites and text to the screen overlay. Drag elements on the canvas to move them; double-click to edit. In text, write {variableName} to show a game variable at runtime.

Play Test

  • WASD / Arrow keys — move.
  • Space / Enter / Z — interact, advance dialogue, confirm a choice.
  • Up / Down — pick a choice option.
  • Esc — stop the test.
